# ugatsu

*[English README](README.md)*

**[デモを開く → ugatsu.dev](https://ugatsu.dev)** — インストール不要。デモは配布物そのもの (書き出せる単一HTMLと同じ一枚) です。

空間一次・テキストネイティブの建築記法 [koyu](https://github.com/kensnzk/koyu) の 2D/3D ビューワー。ソースに形は無い — 平面図・レベルの重ね (2.5D)・立体・面積表は、編集のたびにテキストからその場で生成される。

名は「鑿つ/穿つ」。koyu (戸牖 — 老子第十一章、戸と牖を鑿って室と為す) に対して、テキストに開口を穿って中を覗く行為の名。

## できること

- **読み込み** — `.muro` をドラッグ&ドロップ / ファイル選択で開く。複数の `.muro` を一度にドロップするとレイヤー群として合成する。koyu の実例を同梱 (二室一扉 / 吹抜けつき2フロアのオフィス / 敷地と接道つきの戸建住宅 / **5ファイル合成の戸建** / 10階建て43戸の集合住宅 / そして既定で開く**ショーケース: polygon敷地の9レイヤー合成・11階建て複合ビル**)。
- **編集** — 左ペインがエディタ。一打鍵ごとに再パース → check → 全ビューが追随する。パースエラー時は行番号を示し、画面は最後に整合したモデルを保つ。テキストが原本であり、他はすべて導出物。
- **合成 (koyu ADR-0010)** — `import` で分担されたレイヤー群はタブで行き来する (◈ が base層)。合成は koyu の `parseFiles` — コンフリクト (パス・アセット名の重複) もはみ出し検査も、出所レイヤー:行つきのエラーになり、クリックでそのタブの行へ飛ぶ。建具アセット (`asset` — 引き戸/自動ドアの `style`) は平面の建具表現に効く。
- **平面** — koyu の `plan` と同じ作図規約のインタラクティブ版: 通り芯・壁芯の黒帯・扉の軌跡・吹抜けの対角線・手すりの細実線・半屋外の淡色。クリックで空間選択、ホイールで拡大。
- **3D** — 空間を天井高で押し出し、境界から厚みつきの壁を生成、扉・窓を壁面に、手すりは腰の高さに。用途 / 型 / レベルで色分け、階ごとの表示切替。
- **2.5D 重ね** — 床プレートを実高さ×展開係数で持ち上げて重ねる。void はプレートを置かない — 床の不在がそのまま穴になる。
- **面積表** — レベル別の室リストと小計、ゾーン集計 (専有面積)、用途別面積比、型別集計、CSV書き出し。敷地があれば敷地レポート (宣言/導出面積・建築面積・接道)。
- **グラフ** — 空間を選ぶと隣接 (境界の種別・扉数・耐火) が出る。「扉をいくつ通るか」は `doorsBetween` がそのまま答え、経路は平面上でハイライトされる。
- **書き出し** — ソース / 正準JSON / 平面SVG / 面積表CSV / **モデルを埋め込んだ単一HTML** — 誰でもブラウザで開ける一つのファイル。レイヤー群はそのまま埋め込まれ、開いた側でも分担が見える。

## 使い方

```sh
npm install
npm run dev            # 開発サーバー
npm test               # vitest
npm run typecheck
npm run build          # dist/index.html — ビューワー全体が単一HTML
npm run embed -- examples/mansion.muro   # モデル埋め込みの配布用HTMLを生成
npm run sync-examples  # インストール済み koyu から同梱例を更新
```

ビルド産物は常に単一HTML。`dist/index.html` をそのまま送れば誰でもブラウザで開ける。[ugatsu.dev](https://ugatsu.dev) が配信しているのもこの一枚 — Vercelの静的配信で、デプロイの実体は `vercel.json` だけ ([ADR-0004](docs/decisions/0004-demo-site.md))。

## 構成

```
src/state/       zustand ストア — 原本はソーステキストのみ。モデルは導出物
src/components/  Toolbar / EditorPane / PlanView / Scene3D / AreaTable / Inspector
src/three/       モデル → three.js シーン (3D / 2.5D重ね)
src/lib/         色割当・面積集計・書き出し
examples/        koyu の実例のコピー (sync-examples で追随)
```

koyu はパッケージ (`@kensnzk/koyu`) として消費する — ビューワーは自前の「答え」を持たず、導出 (壁線分・面積・経路・check・採光・敷地) はすべて koyu の関数呼び出しである。設計判断は [docs/decisions/](docs/decisions/) に記録。
